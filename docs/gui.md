# StereoLink 面板手册

`stereo-link.exe` 是 StereoLink（立体声链）的桌面面板，一个双击就能用的 Windows 程序：把系统
声音拆成左 / 右声道，分别推给两台本机播放设备，同时在界面上实时显示整条链路的状态。

![StereoLink 面板](images/gui.png)

- 程序形态：单个 exe（EGUI/OpenGL 绘制），没有安装包、没有后台服务、没有网页前端。
- 运行前提：本机有一个**不会被听见的输出端点**可以当采集源（虚拟音频设备，或没接音箱 / 显示器的
  物理输出）。**零安装就能用**：不用装驱动、不用重启、不用第三方软件。
- 没有现成的无声端点时：运行一次 UU远程（免费，会装好一个虚拟音频设备），或安装可选的
  自研虚拟声卡（高级路径，需测试签名 + 重启一次）。详见
  [`virtual-soundcard.md`](virtual-soundcard.md)。

## 启动前准备

1. **准备一个采集源**（三种任选其一）：
   - 本机已有的**虚拟音频设备**：自研 StereoLink 虚拟声卡（「扬声器 (立体声链虚拟声卡)」）、
     UU远程虚拟音频设备（「扬声器 (UU远程虚拟音频设备)」）、Steam Streaming 等，最省事、无声；
   - 一个**没接音箱 / 显示器的物理输出**：板载 Realtek 扬声器口、空着的 HDMI / DP——不会出声，
     但系统认为它是正常输出，可以回环采集；
   - 都没有 → **先运行一次 UU远程**（免费），它会装好一个虚拟音频设备；回到面板点「刷新设备」，
     在采集源里选「扬声器 (UU远程虚拟音频设备)」。
2. **把两台蓝牙音箱连到本机**：设置 → 蓝牙和设备 → 添加设备；连好后它们会出现在
   「声音 → 输出」列表里。
3. 双击 `stereo-link.exe`。启动后如果采集源已经自动选好，直接点「开始路由」即可。

> 自研虚拟声卡是**可选的高级路径**：驱动是自签的，安装需要开启测试签名并重启一次，Secure Boot
> 必须关闭，桌面会常驻「测试模式」水印。普通用户优先用已有的虚拟设备或 UU远程。

## 分区说明

### 顶栏

| 元素 | 说明 |
| --- | --- |
| 标题 | `StereoLink 立体声链 · 本机设备左右分声道` |
| 运行状态 | 「运行中」= 路由引擎在跑；「已停止」= 没有采集 |
| 默认输出状态 | 「默认输出 = 采集源」或「默认输出未切换」（后者采不到声） |
| 声音设置 | 打开 Windows 的「设置 → 系统 → 声音」 |
| 刷新设备 | 重新枚举本机播放端点（插拔设备、装完 UU远程 / 虚拟声卡后点一下） |
| 右下 toast | 最近一次操作的反馈，显示约 8 秒 |

### 声道路由

实时控制区，也是面板的核心：

- **开始路由 / 停止 / 重启**：启动或停止采集 + 每路播放。开始成功会弹 toast「已开始路由」；
  若左 / 右声道还没选设备，会提示先选择。
- **左右自检音**：往左、右两个目标设备各播放一段测试音，用来确认接线和声道没有接反
  （时长取配置里的 `tone_seconds`，默认 3 秒）。
- **声道表**：左声道 / 右声道各一行，列为「设备、电平、已发流、缓冲、欠载、路径」。
  设备下拉框列出本机 render 端点（已排除当前采集源），下面是实时电平条和该路的累计发送量、
  排队时长、欠载次数、实际写入路径；未运行时显示「未运行」。
- **增益**：0.0–2.0，步进 0.05，默认 1.0。只在开始路由时生效；数字增益超过设备余量会削顶。
- **抖动缓冲**：10–200 ms，步进 5，默认 40。开始路由后生效；蓝牙不稳定、出现欠载时调大。
- **高级：左右微调延迟**：左 / 右各 0–500 ms，用于补偿两只音箱的固定时差（例如一只明显慢
  半拍）；数字越大该路越晚出声。改完立即重启路由生效。
- **声学自校验**：用本机麦克风量出两台音箱的真实到达时间差，自动给较慢的一路垫延迟。
  - 先在下拉里选一个麦克风（内置 / USB / 虚拟 / 回环端点都列出来并标了类别），点「体检」确认
    它真能采到声音；
  - 点「测量并对齐」：先试**同时法**（精度约 ±1 ms），失败退回**依次法**（约 ±4 ms），测完自动
    写入左右微调延迟；
  - 没有麦克风也能用「点击串试听」：按当前延迟值同时放点击串，听到两下就手动微调。
  - 按钮下方状态行显示当前进度 / 结果；测量需要两只音箱都正常出声。
- **采集统计行**：累计采集秒数、数据量、采集源端点名。

修改路由设备或分路设置时会自动保存配置；改动后如果路由在跑，面板会重启路由让新配置生效。

### 采集源

决定引擎从哪个播放端点的 WASAPI 回环流里取声。**这个端点必须同时是 Windows 默认输出**
（面板开始路由时会自动切过去），否则播放器的声音不会流进它。

| 元素 | 说明 |
| --- | --- |
| 类别徽标（右上） | 当前采集源的类别：`虚拟声卡（无声，推荐）` / `物理输出（可能出声）` / `蓝牙音箱（会重复出声，别选）`；找不到端点时显示「未找到」 |
| 当前采集端点 | 大字号显示短名（悬停看全名）；没找到时显示「未找到可用端点」 |
| 系统默认输出 | 当前 Windows 默认播放设备；与采集源一致时带绿色对勾 √，不一致时标黄提醒 |
| 常驻说明 | 「采集源必须同时是 Windows 默认输出，否则采不到声音。」 |
| 采集源下拉 | 列出本机所有 render 端点，每项带类别标注；同名端点按端点 id 精确匹配，不会选错 |
| 「开始路由时自动切为默认输出（退出时切回）」 | 默认勾选。勾选时开始路由会自动把默认输出切成采集源，停止 / 正常退出时切回原来的设备 |
| 切为默认输出 | 手动把默认输出切到采集源（开始路由前也可以先手动切） |
| 恢复原输出 | 切回开始路由前记录的那台设备；没有记录时按钮禁用 |
| 兜底提示（琥珀色） | 当前采集源是物理输出 / 蓝牙时出现：有 UU远程就提示可直接选它；没有就提示三步——① 运行一次 UU远程 → 刷新 → 选「扬声器 (UU远程虚拟音频设备)」；② 安装 StereoLink 虚拟声卡（高级：需测试签名 + 重启一次）；③ 选一个没接音箱的物理输出（可能出声） |

**关于改名**：面板**不再提供虚拟声卡改名**。早期版本的「设备名」输入框、「应用改名」按钮
已经随功能一起删除——改名只影响显示名，对采集和路由没有帮助，需要时只能改驱动 INF 重新签名
安装。仓库里保留的 `scripts\gui-set-name.ps1`、`scripts\rename-endpoint.ps1` 只是底层开发
工具，面板不调用。

### 本机播放设备

列出当前系统里所有 render 端点：

| 列 | 说明 |
| --- | --- |
| 设备 | 端点友好名（例如 `扬声器 (Xiaomi Sound-1695)`）；默认输出显示为绿色，悬停看全名 |
| 格式 | 该端点当前混音格式；点开下拉框改（见下） |
| 角色 | 徽章：`默认输出` / `采集源` / `左声道` / `右声道`（可同时多个） |
| 操作 | 非采集源的设备可点「设为左」「设为右」；采集源那一行只显示标记 |

**格式设置**：每行「格式」列是一个下拉框（44.1 / 48 / 96 kHz × 立体声 × 16 / 24 / 32 bit，
32 bit 为浮点）加一段只读灰字显示当前格式。下拉框只列出**该设备真正支持**的格式（后台逐个
探测），选中某项**立刻生效**：不用管理员、不用重启音频服务、不用重启面板，旁边灰字马上变成
新格式。

- 底层和 Windows「声音设置」面板用同一个未公开接口 `IPolicyConfig::SetDeviceFormat`，所以效果
  和手动改设备属性一致；改完立刻读回校验，不一致会红字报错。
- 不写注册表、不需要备份；改坏了把下拉框选回原格式即可。
- 某些设备不支持某格式时系统可能自动回退或短时无声，重新选回原格式即可恢复。

### 诊断

面板启动时和运行中自动检查，每条带状态图标：

- `✓` 正常；`!` 需要注意；`×` 明确有问题。
- 常见条目：采集源是否就绪、是否找到可用采集源、左 / 右声道是否已选择、路由是否在运行、
  两条链路有没有错误或欠载、系统默认输出是不是采集源。
- 「复制」把全部诊断项和日志摘要复制到剪贴板，方便贴给别人排查。

### 怎么用 / 日志

「怎么用」是一份四步上手说明，并显示当前配置下的**软件侧延迟**（20 ms 采集缓冲 + 抖动缓冲 +
渲染缓冲的一半）和中文字体检查结果：

- 找不到中文字体时中文可能显示为方块，面板会给出警告并列出候选字体目录。
- 「显示日志面板」勾选后下方出现日志区。

日志区显示面板进程内的 tracing 日志（默认最多 1000 行），行首是相对启动的秒数；「清空」
只清界面缓冲。日志不落盘，需要留证时点诊断里的「复制」。

## 推荐操作流程

1. 打开面板，在「采集源」卡里选一个无声的本机输出端点（虚拟音频设备优先；没有就先跑一次
   UU远程再刷新）。确认「系统默认输出」一项与采集源一致（或勾选自动切换）。
2. 连好两台蓝牙音箱，点一次「刷新设备」。
3. 在「声道路由」里给左声道选设备 A、右声道选设备 B（也可以用「本机播放设备」里的
   「设为左」「设为右」）。
4. 点「左右自检音」：确认左右两只箱子各自出声且**方向正确**（左箱只出左声道）。房间固定的
   话可以跑一次「声学自校验」自动对齐两只箱的到达时间。
5. 点「开始路由」。用任意播放器放歌 / 看视频，声音就被拆成左右两路。
6. 退出程序会自动停路由并恢复默认输出；如果上次被强杀，手动点一次「恢复原输出」。

## 参数怎么调

| 场景 | 调整 |
| --- | --- |
| 声音断续、统计里「欠载」在涨 | 把「抖动缓冲」调大（40 → 60 / 100 ms）；蓝牙距离拉近，断开其它蓝牙设备 |
| 延迟嫌大 | 把「抖动缓冲」调小（最小 10 ms），但要接受更频繁的欠载风险 |
| 两只音箱不同步 | 用「声学自校验」让麦克风自动测量并对齐；没有麦克风就展开「高级：左右微调延迟」，给**声音较早的那只**加 10–50 ms，或用「点击串试听」边听边调 |
| 接反了左右 | 对调左 / 右声道的设备选择，再点一次「重启」 |
| 采集源自己出声 | 换成虚拟音频设备或没接音箱的物理输出 |

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 「采集源」显示「未找到可用端点」 | 点「刷新设备」；本机至少要有输出端点。没有虚拟音频设备就先运行一次 UU远程（或安装自研虚拟声卡），再刷新 |
| 不知道选哪个采集源 | 优先选没有声音的虚拟音频设备（类别徽标会写「虚拟声卡（无声，推荐）」）；其次是没接音箱 / 显示器的物理输出；别选蓝牙音箱 |
| 点了开始路由但没声音 | 采集源必须同时是 Windows 默认输出：看「系统默认输出」是否带 √，或点「切为默认输出」 |
| 采集源在出声（听到两遍 / 漏音） | 采集源选错了：换成虚拟音频设备，或一个没接音箱的物理输出 |
| 本机没有虚拟音频设备 | 运行一次 UU远程（免费，会装好一个虚拟音频设备）→ 点「刷新设备」→ 选「扬声器 (UU远程虚拟音频设备)」；或安装自研虚拟声卡（高级路径） |
| 点「开始路由」失败 | 多半是没选左 / 右设备，或两台选了同一个端点、或采集源找不到；按 toast 提示检查 |
| 有电平但听不到声音 | 目标设备本身是否静音 / 音量太低；蓝牙音箱是否被系统连到了别的输出；用「左右自检音」单独确认 |
| 一边没声音 | 看该路电平条：不动说明目标设备写失败（日志里有原因），动但没声查音箱音量 / 连线 |
| 默认输出没自动切 | 检查勾选、点「切为默认输出」；被其它程序独占或系统策略限制时会失败，可手动切 |
| 两只音箱到达时间不一样 | 用「声学自校验」测量并对齐；没有麦克风就用「点击串试听」手动调左右微调延迟 |
| 声学自校验测不出来 | 确认麦克风能采到声音（先点「体检」）、两只音箱都在出声；「同时法」失败会自动退回「依次法」，仍失败就手动微调 |
| 退出 / 强杀后默认输出没恢复 | 只有正常退出才会恢复；崩溃或被强杀时，到「设置 → 系统 → 声音」手动切回，或下次打开面板点「恢复原输出」 |
| 改格式后设备没声音 / 声音异常 | 设备不支持该格式时可能自动回退或短时无声；把下拉框选回原格式即可（不写注册表、无需备份） |
| 面板中文显示成方块 | 系统缺少中文字体；安装任一中文字体（如思源黑体 / 微软雅黑）后重启面板 |
| 装了自研虚拟声卡后，输出列表里没有「扬声器 (立体声链虚拟声卡)」 | 先确认 `pnputil /enum-devices /instanceid "ROOT\MEDIA\0001"` 为 `Status: Started`；否则按 `安装虚拟声卡.cmd` 提示重启 |
| 自研虚拟声卡带黄色叹号 / Code 52 | 测试签名没生效：确认 `bcdedit /enum {current}` 含 `testsigning Yes`，改完重启；Secure Boot 必须关闭 |
| 想改虚拟声卡显示名 | 面板已不提供改名。显示名不影响采集，一般不需要改；确实要改只能改驱动 INF 后重新签名安装 |

## 已知限制

- 面板当前只暴露左 / 右两路（底层路由引擎支持任意多路、每条可选左 / 右 / 双声道混音，
  面板暂未开放）；只有一只音箱时没有单箱混音入口。
- 没有托盘图标、没有开机自启；关窗口 = 停路由。
- 采集源必须同时是 Windows 默认输出；开始路由时自动切换，停止 / 正常退出时恢复。**异常退出
  （崩溃 / 被强杀 / 断电）不会恢复**，需要手动切回。
- 自研虚拟声卡是可选高级路径：自签内核驱动，安装需要管理员权限、开启测试签名（桌面会有
  「测试模式」水印）并关闭 Secure Boot；卸载后要重启一次才彻底消失。
- 面板不再提供虚拟声卡改名功能（早期版本的「设备名 / 应用改名」已删除）。
- 蓝牙链路的延迟在音箱固件侧（≈0.2–0.35 s，估计），面板只能优化软件侧约 80 ms。
- 妙播云投放 / AirPlay / DLNA 等网络投放功能已从本产品删除，面板不再提供相关入口。
