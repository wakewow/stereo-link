# StereoLink 面板手册

`stereo-link.exe` 是 StereoLink（立体声链）的桌面面板，一个双击就能用的 Windows 程序：把系统
声音拆成左 / 右声道，分别推给两台本机播放设备，同时在界面上实时显示整条链路的状态。

![StereoLink 面板](images/gui.png)

- 程序形态：单个 exe（EGUI/OpenGL 绘制），没有安装包、没有后台服务、没有网页前端。
- 运行前提：已安装虚拟声卡（`安装虚拟声卡.cmd`，需要开启测试签名并重启一次），Windows 输出
  列表里有 **「扬声器 (立体声链虚拟声卡)」**。
- 虚拟声卡来源、构建签名与卸载见 [`virtual-soundcard.md`](virtual-soundcard.md)。

## 启动前准备

1. **安装虚拟声卡**（只需一次，管理员权限）：右键仓库根目录的 `安装虚拟声卡.cmd` →
   「以管理员身份运行」，UAC 确认。脚本会开启测试签名、导入自签证书、安装自研驱动
   `StereoLinkVad`；**按提示重启一次电脑**（重启后桌面出现「测试模式」水印属正常）。
   重启后「设置 → 系统 → 声音 → 输出」里出现「扬声器 (立体声链虚拟声卡)」即成功。
2. **把两台蓝牙音箱连到本机**：设置 → 蓝牙和设备 → 添加设备；连好后它们会出现在
   「声音 → 输出」列表里。
3. 双击 `stereo-link.exe`。

> 驱动是自签的：Secure Boot 必须关闭，且 `bcdedit` 里要有 `testsigning Yes`（安装脚本会自动开）。
> 没装好时面板右上角会提示找不到虚拟声卡。

## 分区说明

### 顶栏

| 元素 | 说明 |
| --- | --- |
| 标题 | `StereoLink 立体声链 · 本机设备左右分声道` |
| 运行状态 | 「运行中」= 路由引擎在跑；「已停止」= 没有采集 |
| 默认输出状态 | 「默认输出 = 虚拟声卡」或「默认输出未切换」 |
| 声音设置 | 打开 Windows 的「设置 → 系统 → 声音」 |
| 刷新设备 | 重新枚举本机播放端点（插拔设备后点一下） |
| 右下 toast | 最近一次操作的反馈，显示约 8 秒 |

### 声道路由

实时控制区，也是面板的核心：

- **开始路由 / 停止 / 重启**：启动或停止采集 + 每路播放。开始成功会弹 toast「已开始路由」；
  若左 / 右声道还没选设备，会提示先选择。
- **左右自检音**：往左、右两个目标设备各播放一段测试音，用来确认接线和声道没有接反
  （时长取配置里的 `tone_seconds`，默认 3 秒）。
- **左声道 / 右声道**：各一个下拉框，列出本机 render 端点（已排除虚拟声卡自身）。下拉框下方
  是实时电平条和该路的累计发送量、排队时长、欠载次数；未运行时显示「未运行」。
- **增益**：0.0–2.0，步进 0.05，默认 1.0。只在开始路由时生效。
- **抖动缓冲**：10–200 ms，步进 5，默认 40。开始路由后生效；蓝牙不稳定、出现欠载时调大。
- **高级：左右微调延迟**：左 / 右各 0–500 ms，用于补偿两只音箱的固定时差（例如一只明显慢
  半拍）；数字越大该路越晚出声。
- **采集状态行**：累计采集秒数、数据量、采集源端点名。

修改路由设备或分路设置时会自动保存配置；改动后如果路由在跑，面板会重启路由让新配置生效。

### 本机播放设备

列出当前系统里所有 render 端点：

| 列 | 说明 |
| --- | --- |
| 设备 | 端点友好名（例如 `扬声器 (Xiaomi Sound-1695)`） |
| 格式 | 该端点的混音格式（采样率 / 声道 / 位深） |
| 角色 | 徽章：`默认输出` / `采集源` / `左` / `右` |
| 操作 | 非虚拟声卡、非当前左 / 右设备可点「设为左」「设为右」；格式在下拉框里直接改（见下） |

**格式设置**：每行「格式」列是一个下拉框（44.1 / 48 / 96 kHz × 立体声 × 16 / 24 / 32 bit，
32 bit 为浮点）加一段只读灰字显示当前格式。选中某项**立刻生效**：不用管理员、不用重启音频
服务、不用重启面板，旁边灰字马上变成新格式。

- 底层和 Windows「声音设置」面板用同一个未公开接口 `IPolicyConfig::SetDeviceFormat`，所以效果
  和手动改设备属性一致；改完立刻读回校验，不一致会红字报错。
- 不写注册表、不需要备份；改坏了把下拉框选回原格式即可。
- 某些设备不支持某格式时系统可能自动回退或短时无声，重新选回原格式即可恢复。

### 虚拟声卡

| 元素 | 说明 |
| --- | --- |
| 设备名（标题行） | 当前虚拟声卡的端点显示名，默认「扬声器 (立体声链虚拟声卡)」；找不到驱动时显示「未找到」 |
| 系统默认输出 | 当前 Windows 默认播放设备；指向虚拟声卡时带绿色对勾 |
| 「开始路由时自动切为默认输出（退出时切回）」 | 默认勾选。勾选时开始路由会自动把默认输出切成虚拟声卡，并在正常退出时切回原来的设备 |
| 切为默认输出 | 手动把默认输出切到虚拟声卡（开始路由前也可以先手动切） |
| 恢复原输出 | 切回之前记录的那台设备；没有记录时按钮禁用 |
| 「设备名」输入框 | 预填当前设备名（默认「立体声链虚拟声卡」），可直接编辑；悬停提示「Windows 声音列表里显示成「扬声器 (这个名字)」」 |
| 应用改名 | 把输入框里的名字应用到虚拟声卡：面板释放内嵌的 `scripts\gui-set-name.ps1` 并调用，脚本自己弹 UAC（管理员）→ 用 `reg export` 备份 `Enum\ROOT\MEDIA\0001` 到 `%TEMP%\stereo-link\backups\` → 写 `FriendlyName` → 重启 `AudioEndpointBuilder`（约 2–4 秒音频中断）并轮询读回校验 → 面板刷新设备列表。校验规则：名字 1–64 个字符、不能含 `\ / : * ? " < > \|`、不能全是空格；不合法时面板红字提示、不发起提权。改名前会先校验，等待授权期间按钮禁用并显示加载圈 |
| 提示文字 | 说明「把 Windows 输出选成虚拟声卡后，播放器声音才会流进分离链路」 |

改名日志在 `%TEMP%\stereo-link\rename.log`；UAC 取消或脚本失败时面板 toast 会报错，日志里有
`EXITCODE=` 结尾的完整过程。注意改名只写注册表里的运行时设备名，重装驱动后会回到驱动 INF 里的
默认名（「立体声链虚拟声卡」）。

`scripts\rename-endpoint.ps1` 是通用命令行改名工具（支持 `-Rollback` 回滚、`-DryRun` 试运行），
会额外 disable/enable 设备一次，Win11 上可能留下 pending-reboot；面板不直接调用它。手动使用示例：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\rename-endpoint.ps1 `
  -DeviceInstanceId ROOT\MEDIA\0001 -NewName "立体声链虚拟声卡"
```

安装 / 卸载驱动与 testsigning 细节见 [`virtual-soundcard.md`](virtual-soundcard.md)。

### 诊断

面板启动时和运行中自动检查，每条带状态图标：

- `✓` 正常；`!` 需要注意；`×` 明确有问题。
- 常见条目：虚拟声卡端点是否存在、系统默认输出是否指向它、左 / 右声道是否已选择、路由
  是否在运行、采集源是否找到。
- 「复制」把全部诊断项和日志摘要复制到剪贴板，方便贴给别人排查。

### 怎么用 / 日志

「怎么用」是一份四步上手说明，并显示当前配置下的**软件侧延迟**（抖动缓冲 + 40 ms 渲染缓冲）
和中文字体检查结果：

- 找不到中文字体时中文可能显示为方块，面板会给出警告并列出候选字体目录。
- 「显示日志面板」勾选后下方出现日志区。

日志区显示面板进程内的 tracing 日志（默认最多 1000 行），行首是相对启动的秒数；「清空」
只清界面缓冲。日志不落盘，需要留证时点诊断里的「复制」。

## 推荐操作流程

1. 插好 / 连好两台蓝牙音箱，打开面板，点一次「刷新设备」。
2. 在「声道路由」里给左声道选设备 A、右声道选设备 B（也可以用「本机播放设备」里的
   「设为左」「设为右」）。
3. 点「左右自检音」：确认左右两只箱子各自出声且**方向正确**（左箱只出左声道）。
4. 点「开始路由」（保持「自动切为默认输出」勾选）。用任意播放器放歌 / 看视频。
5. 声音稳定后不用再动面板；退出程序会自动停路由并恢复默认输出。

## 参数怎么调

| 场景 | 调整 |
| --- | --- |
| 声音断续、统计里「欠载」在涨 | 把「抖动缓冲」调大（40 → 60 / 100 ms）；蓝牙距离拉近，断开其它蓝牙设备 |
| 延迟嫌大 | 把「抖动缓冲」调小（最小 10 ms），但要接受更频繁的欠载风险 |
| 两只音箱不同步 | 展开「高级：左右微调延迟」，给**声音较早的那只**加 10–50 ms，直到听感对齐 |
| 接反了左右 | 对调左 / 右声道的设备选择，再点一次「重启」 |

## 配置与数据路径

| 路径 | 内容 |
| --- | --- |
| `%APPDATA%\stereo-link\config.json` | 面板配置（没有 `APPDATA` 时在 exe 同目录）；改完需重启面板生效，界面上的改动会自动保存 |
| `%TEMP%\stereo-link\switch-audio-default.ps1` | 切换默认输出的临时脚本，由面板从内嵌资源释放 |
| `%TEMP%\stereo-link\rename.log` | 「应用改名」的执行日志（含 `EXITCODE=`） |
| `%TEMP%\stereo-link\backups\` | 面板「应用改名」前的注册表备份（`.reg`）；含本机设备实例路径，不要外传 |
| `scripts\backups\` | 命令行改名工具 `scripts\rename-endpoint.ps1` 的备份目录 |

配置字段含义见仓库根目录 [`README.md`](../README.md) 的「配置与数据路径」一节。

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 启动后「虚拟声卡」区显示「未找到」 | 先跑 `安装虚拟声卡.cmd`（管理员）并按提示重启；重启后确认 `pnputil /enum-devices /instanceid "ROOT\MEDIA\0001"` 为 `Status: Started`，设备管理器里 StereoLinkVad 无黄色叹号 |
| 设备管理器里 StereoLinkVad 带黄色叹号 / Code 52 | 测试签名没生效：确认 `bcdedit /enum {current}` 含 `testsigning Yes`，改完重启；Secure Boot 必须关闭 |
| 桌面出现「测试模式」水印 | testsigning 已开启的正常现象，不影响使用；卸载虚拟声卡时可选关闭 |
| 点「开始路由」失败 | 多半是没选左 / 右设备，或两台选了同一个端点；按 toast 提示检查 |
| 有电平但听不到声音 | 目标设备本身是否静音 / 音量太低；蓝牙音箱是否被系统连到了别的输出；用「左右自检音」单独确认 |
| 一边没声音 | 看该路电平条：不动说明目标设备写失败（日志里有原因），动但没声查音箱音量 / 连线 |
| 默认输出没自动切 | 检查勾选、点「切为默认输出」；被其它程序独占或系统策略限制时会失败，可手动切 |
| 改名提示名字不合法 | 名字需 1–64 个字符、不能含 `\ / : * ? " < > \|`、不能全是空格；按红字提示修改后再点「应用改名」 |
| 改名后输出列表里名字没变 | 等 2–4 秒并点「刷新设备」，必要时重启面板；UAC 被取消会回滚，失败原因看日志 |
| 改格式后设备没声音 / 声音异常 | 设备不支持该格式时可能自动回退或短时无声；把下拉框选回原格式即可（不写注册表、无需备份） |
| 退出后默认输出没恢复 | 只有正常退出才会恢复；崩溃或被强杀时，到「设置 → 系统 → 声音」手动切回 |
| 面板中文显示成方块 | 系统缺少中文字体；安装任一中文字体（如思源黑体 / 微软雅黑）后重启面板 |
| 想恢复虚拟声卡默认名 | 在「设备名」里填回 `立体声链虚拟声卡` →「应用改名」；要彻底移除驱动就运行 `卸载虚拟声卡.cmd` |

## 已知限制

- 面板当前只暴露左 / 右两路（底层路由引擎支持任意多路、每条可选左 / 右 / 双声道混音，
  面板暂未开放）；只有一只音箱时没有单箱混音入口。
- 没有托盘图标、没有开机自启；关窗口 = 停路由。
- 虚拟声卡是自签内核驱动：安装需要管理员权限、开启测试签名（桌面会有「测试模式」水印）并关闭
  Secure Boot；卸载后要重启一次才彻底消失。
- 改名需要管理员提权（UAC）并短暂中断音频（约 2–4 秒）；改格式立即生效、无需提权、不中断音频服务。
- 蓝牙链路的延迟在音箱固件侧（≈0.2–0.35 s，估计），面板只能优化软件侧约 80 ms。
- 妙播云投放 / AirPlay / DLNA 等网络投放功能已从本产品删除，面板不再提供相关入口。
